Repository activity — directory row prototype

Throwaway prototype. Answers one question: what does “last updated” look like inside the Repository cell, in each state it can be in.

What to look at. The second line under each GitHub link is the whole feature — no 7th column, so filterDirectory()’s td[4]/td[5] indexes are untouched. Hover a value for the exact date (title); the visible string is computed from <time datetime> at render, bucketed to day granularity so a cached value can’t render a visibly wrong answer. Switch to Loading to confirm the skeleton reserves the same height and nothing reflows. “Repo unavailable” (404, private, deleted) and “rate-limited” both render a neutral —: never an error, never a status code. Show repo stats is not part of the initial implementation. It exists here only to show that the Repository cell doesn’t dead-end when contributors and stars arrive later — and that the disclosure is what will gate the contributors call, which can’t afford to be per-row. v1 is the second line and nothing else.
